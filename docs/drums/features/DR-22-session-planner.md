# DR-22 — Drum session planner: today's practice, budgeted

**Phase:** D2 · **Effort:** S–M · **Depends on:** DR-16, DR-21, the trainers it opens ·
**Blocks:** the daily-habit loop

## Why

The researched session template (../research-2026-08-15.md §1) is concrete: 30 minutes =
5 warmup / 5 timing / 10 grooves / 5 rudiments / 5 play-along; consistency beats length.
The piano app's `planSession` (15/30/60 budgets, mix ratios, real candidates) is this
exact machine, already built and battle-tested through its M4 acceptance.

## What it is

- **Drum session mix** over the existing planner core: warm-up (SRS due items + one tier-1
  rudiment) / timing (a DR-12 exercise: gap click or subdivision block) / grooves &
  coordination (current lesson's exercises) / fills / apply (play-along DR-26 once it
  exists; a full-groove run before that). Ratios per the researched template, adjustable
  like piano's (the REQ-3.1.4 "adjustable" clause, honored from day one this time).
- **Candidates** drawn from: current DR-17/27 lesson exercises, DR-21 due queue, weakest
  recent stats (DR-23's per-limb bias and worst-groove data — "your kick has rushed all
  week: 5 minutes of kick permutations").
- **Per-instrument Today:** the drums Today screen owns the drum plan; the shared streak
  counts a day practiced if either instrument was (one habit — DR-01's decision,
  restated).
- Each planned item opens its trainer preloaded and marks itself done on completion
  (the piano 4.7a pattern, including its "each item opens the drill it names" proof).

## Experience-gate proof

Cold drums profile, 30-min budget: plan shows the template's blocks with real candidates;
on a seeded profile with due SRS items and a rushing-kick bias, the plan visibly contains
both responses; completing an item ticks it and the session log records it; budget switch
15/30/60 re-plans proportionally, driven. Both widths/themes.
